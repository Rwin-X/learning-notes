SIGIL

Every ring is a band of words set side by side, edge to edge, wrapped around the sphere and turning with it. The outer shell carries terminal commands, the middle one link status, the inner one dialogue. The digest bytes of SHA-256 and SHA-512 decide which words fill each ring, so the same input always reads the same.
