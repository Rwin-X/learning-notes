## Vault Rules
1. **Every note is atomic.** One concept, one file. If a note needs an "and" in the title, split it.
2. **Inbox → Process → Permanent.** Nothing stays in `00-Inbox` more than 7 days. Either it becomes a real note or it dies.
3. **Link liberally, tag sparingly.** Prefer `[[wikilinks]]` over tags for connecting ideas. Tags are for note *type* and *status* only.
4. **No orphan notes.** Every permanent note links to at least one MOC.
5. **English only in code, tool output, and technical fields** — Persian is fine in your own reflective commentary if you want it, but keep terminal-facing content in English so it stays portable.
