# Penetration Testing (Ethical Hacking)

Authorized, deliberate attempts to break into a system — using the same
techniques real attackers would ([[Port and Port Scanning]],
[[SQL Injection]], social engineering, etc.) — in order to find and fix
weaknesses before a malicious actor does. Authorization and scope are
what make it "ethical" rather than illegal: the same technical action
(scanning, exploiting) is a crime without permission and a job with it.

Closely related to, but distinct from, a [[Bug Bounty]] program: pentesting
is typically a scoped, contracted engagement; bug bounties are an
open-ended standing invitation with per-vulnerability rewards.

Findings often get tracked against known vulnerability databases — see
[[Common Vulnerabilities and Exposures CVE]] in Week 3.
