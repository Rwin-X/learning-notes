# Bug Bounty

A program where organizations pay independent researchers for
responsibly disclosing vulnerabilities they find, rather than the
researcher selling the flaw elsewhere or exploiting it themselves.
Creates a legal, incentivized channel for the same skills used in
[[Penetration Testing]] and [[Cracking and Reverse Engineering]],
open-ended and ongoing rather than a single scoped engagement.

Findings typically get assessed for severity (see
[[CVSS EPSS and KEV]]) and, once patched, often result in a public
[[Common Vulnerabilities and Exposures CVE]] entry crediting the
researcher — aligning researcher incentives with disclosure that actually
improves security for everyone using the software, rather than only
benefiting the finder.
