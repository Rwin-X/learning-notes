# OWASP (Open Worldwide Application Security Project)

A nonprofit community producing widely-used, freely available resources
on web application security — most notably the "OWASP Top 10," a
regularly updated ranking of the most critical web application security
risks (injection attacks, broken access control, and similar categories
covered throughout this week are consistent fixtures on it).

Functions as a shared reference point across the industry for
prioritizing what to defend against first, and connects practically to
[[Penetration Testing]] and [[Bug Bounty]] work, which commonly scope
findings against OWASP categories.
