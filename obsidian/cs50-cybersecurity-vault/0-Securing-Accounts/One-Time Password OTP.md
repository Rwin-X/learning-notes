# One-Time Password (OTP)

A password valid for a single login or a short time window, typically
generated by an app or sent via SMS. The standard "possession" factor in
[[Multi-Factor Authentication Factors]] used to implement
[[Two-Factor Authentication 2FA]].

SMS-delivered OTPs are weaker than app-generated ones because SMS can be
intercepted via [[SIM Swapping]] — the phone number, not the physical
device, is what's actually being verified.
