# Keylogging

Software (or hardware) that silently records every keystroke, capturing
passwords and other sensitive input as they're typed — bypassing password
strength entirely, since the attacker gets the plaintext directly at the
point of entry.

Usually delivered as [[Malware]] (Week 2) via [[Phishing]] or
compromised software. Defeats [[Usernames and Passwords]] regardless of
complexity, which is part of why [[Two-Factor Authentication 2FA]] is
valuable — a logged keystroke doesn't include a possession-based OTP
generated on a separate device.
