# Web Browsing History

The record of sites visited, stored locally by the browser. Useful (autofill,
revisiting pages) but also a privacy exposure — anyone with access to the
device can see where you've been.

Clearing it has a real limit worth internalizing: it only removes the
*local* record. It does not undo the fact that every site visited already
logged the visit server-side — see [[Logs]]. Clearing history protects
against someone with access to *your device*; it does nothing against
what the sites themselves, or anyone watching network traffic in
transit, already recorded.
