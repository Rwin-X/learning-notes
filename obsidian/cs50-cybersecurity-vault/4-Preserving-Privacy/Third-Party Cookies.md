# Third-Party Cookies

A cookie set not by the site the user is currently visiting (first-party)
but by a *different* domain embedded within that page — typically an
advertising or analytics script loaded on many different sites at once.
Because the same third-party domain appears across thousands of unrelated
sites, it can recognize the same
[[Session Cookies vs Tracking Cookies|tracking cookie]] on each one,
building a cross-site browsing profile the user never explicitly agreed
to on any single visit.

This is the mechanism behind most cross-site ad targeting, and the main
target of recent browser privacy changes — many browsers now block or
are phasing out third-party cookies by default specifically because this
cross-site linkage is the core privacy problem, distinct from ordinary
first-party cookies used for login sessions on a single site.
