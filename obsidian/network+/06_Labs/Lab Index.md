# Lab Index

Practical reinforcement — pairs with theory notes in the domain folders. Add a new note per lab as you build.

## Suggested Labs (build over consume)

- [ ] Subnet a /24 into 8 equal subnets by hand, then verify with a calculator.
- [ ] Set up two VMs, capture traffic with Wireshark, identify TCP 3-way handshake.
- [ ] Configure DHCP scope + reservation on a home router or pfSense/VM.
- [ ] Build a simple VLAN topology in GNS3/Packet Tracer, test trunk vs access ports.
- [ ] Run `tcpdump`/Wireshark during a DNS lookup, map out query/response.
- [ ] Simulate ARP spoofing in an isolated lab VM (tie into your OSCP track — ethically, isolated network only).
- [ ] Practice `traceroute`/`tracert` against a few public hosts, interpret hop latency.
- [ ] Configure static routes between two virtual routers, verify with routing table.
