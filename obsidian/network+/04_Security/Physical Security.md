# Physical Security

## Controls

- **Badge/access card systems**: authentication for physical entry.
- **Biometrics**: fingerprint, retina, facial recognition.
- **Mantrap**: two interlocking doors, only one opens at a time — prevents tailgating.
- **Cameras/CCTV**: deterrence and evidence, not prevention alone.
- **Locks (cipher locks, smart locks)**: physical access control on doors/racks.
- **Asset tracking tags**: inventory and theft deterrence.

## Environmental

- **HVAC**: temperature/humidity control for equipment rooms.
- **Fire suppression**: clean agent systems (FM-200) preferred over water/sprinklers in server rooms.
- **UPS**: short-term power during outage/transfer.
- **Generator**: long-term backup power.

## Common Exam Traps

- Mantrap specifically defeats tailgating — if the question describes "someone following an authorized person through a door," the answer is mantrap.
- Cameras deter/record but don't physically prevent access — don't pick "camera" for a "prevent access" question.
