# Documentation, Diagrams, and Policies

## Diagram Types

- **Physical network diagram**: actual cabling, hardware, rack layout.
- **Logical network diagram**: IP addressing, VLANs, traffic flow — abstracted from physical.
- **Wiring diagram**: cable-level detail, port-to-port mapping.
- **Rack diagram**: physical placement in a server rack.

## Policies

- **SLA (Service Level Agreement)**: uptime/performance commitment with a vendor.
- **MOU (Memorandum of Understanding)**: informal agreement between parties.
- **NDA (Non-Disclosure Agreement)**: confidentiality terms.
- **AUP (Acceptable Use Policy)**: rules for appropriate use of company resources.
- **BYOD**: policy governing personal device use on corporate network.
- **Change management**: formal process for approving/documenting network changes (request → approval → implementation → review).

## Common Exam Traps

- Physical vs logical diagram confusion — logical = IP/VLAN/data flow, physical = actual wires and boxes.
- Change management questions test the *order* of steps, not just definitions.
