# Network Automation Basics

## Key Concepts

- **Infrastructure as Code (IaC)**: define network/infra config in version-controlled files instead of manual changes.
- **Orchestration**: coordinating multiple automated tasks/systems together (vs automation = a single task).
- **API-driven config**: REST APIs let tools push config to devices programmatically (vs manual CLI).
- **Playbooks**: automation scripts (e.g., Ansible) that define desired device state.

## Why It's Tested (N10-009 addition)

CompTIA added automation/SDN emphasis to reflect modern network operations moving away from box-by-box CLI configuration toward centralized, programmatic management.

## Common Exam Traps

- Automation = single repeatable task. Orchestration = coordinating multiple automated tasks across systems. The exam tests this distinction directly.
