# Cheatsheet Syntax

## Purpose
Quick reference for core Ruby syntax.

## Explanation
A condensed reference covering the syntax introduced across [[Foundations MOC]] — variables, conditionals, loops, and method definitions — for fast lookup while coding rather than re-reading full notes.

## Examples
```ruby
# Variables
x = 5

# Conditionals
if x > 0 then puts "pos" elsif x < 0 then puts "neg" else puts "zero" end

# Loops
3.times { |i| puts i }
arr.each { |el| puts el }

# Methods
def add(a, b) = a + b   # endless method (Ruby 3+)
```
