# Cheatsheet String Methods

## Purpose
Quick reference for common String methods.

## Explanation
Fast lookup for the [[Strings]] method set — formatting, searching, and transforming text, used constantly across nearly every project.

## Examples
```ruby
str.strip / str.chomp        # remove whitespace/newline
str.split(",")                # -> Array
str.gsub("a", "b")            # replace all
str.include?("sub")           # substring check
str.capitalize / str.downcase / str.upcase
```
