# Resource Docs and Sites

## Purpose
Key official documentation and reference sites for day-to-day lookup.

## Explanation
The official Ruby docs (ruby-doc.org) are the ground truth for any method signature question — use them to verify anything in the [[Cheatsheet Array and Hash Methods|cheatsheets]]. RubyGems.org (see [[RubyGems]]) is the registry for finding gems.

## Examples
```
ruby-doc.org        -- official API docs
rubygems.org         -- gem registry
rubocop.org           -- style guide + linter docs
```
