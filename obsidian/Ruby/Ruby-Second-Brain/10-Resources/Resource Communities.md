# Resource Communities

## Purpose
Places to ask questions and stay current with the Ruby community.

## Explanation
Communities worth following once you're past [[Foundations MOC]] and want real feedback on code — r/ruby, the Ruby subreddit's weekly threads, and Ruby-focused Discord/Slack communities. Useful for validating approach on your [[Projects MOC|projects]] before considering them "done".

## Examples
```
r/ruby (Reddit)
Ruby community Discord servers
Local Ruby meetups / RubyConf talks (many on YouTube)
```
