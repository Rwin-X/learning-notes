# Exercises Foundations

## Purpose
Drill core syntax, variables, conditionals, and loops with small practice problems.

## Explanation
A working set of short problems to solidify [[Foundations MOC]] material before moving into OOP. Solve each without looking up syntax — struggle first, check the relevant atomic note only after attempting.

Recommended order: work through these alongside [[Ruby Syntax Basics]] through [[Exception Handling Basics]], then attempt [[Project Number Guessing Game]] as a synthesis exercise.

## Examples
```ruby
# 1. FizzBuzz: print 1-100, but "Fizz" for multiples of 3,
#    "Buzz" for multiples of 5, "FizzBuzz" for both.

# 2. Write a method `palindrome?(str)` that returns true/false.

# 3. Write a method that returns the largest of 3 numbers
#    without using .max
```
