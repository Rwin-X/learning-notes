# Exercises Advanced

## Purpose
Practice closures, error handling, and file operations.

## Explanation
Problems combining [[Blocks Procs and Lambdas]], [[Exception Handling Advanced]], and [[File IO]] — the topics that most directly prepare you for the [[Project Contact Book with File Persistence]] capstone.

These are intentionally open-ended; there's no single correct implementation.

## Examples
```ruby
# 1. Write a `retry_operation` method that retries a block up to
#    3 times if it raises, using begin/rescue/retry.

# 2. Write a method that reads a file and returns word count,
#    handling the case where the file doesn't exist.

# 3. Build a simple memoizing lambda using a closure.
```
