# Exercises OOP

## Purpose
Practice designing classes, inheritance hierarchies, and modules.

## Explanation
Problems focused on applying [[OOP MOC]] concepts in small, self-contained class designs. Each problem should be solvable using only [[Classes and Objects]] through [[Structs]].

After these, attempt [[Project Simple Bank Account System]] to combine the concepts into a cohesive program.

## Examples
```ruby
# 1. Create a `Shape` base class with subclasses `Circle` and
#    `Square`, each implementing an `area` method (Polymorphism).

# 2. Add a `Comparable`-based ranking to a `Player` class by score.

# 3. Use attr_accessor to build a `Car` class with make/model/year.
```
