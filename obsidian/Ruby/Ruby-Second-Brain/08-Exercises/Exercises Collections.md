# Exercises Collections

## Purpose
Practice array and hash transformations using Enumerable methods.

## Explanation
Problems that force you to reach for `map`, `select`, `reduce`, `group_by`, and `each_with_object` instead of manual loops — reinforcing [[Array Methods (map select reduce)]] and [[Enumerable Deep Dive]].

Follow these with [[Project Word Frequency Counter]] for a realistic application.

## Examples
```ruby
# 1. Given an array of numbers, return only primes.

# 2. Given an array of words, group them by their first letter.

# 3. Given a hash of {name: score}, return the name with the
#    highest score without using .max_by
```
