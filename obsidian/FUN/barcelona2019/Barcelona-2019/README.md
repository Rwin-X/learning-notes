# Barcelona 2019 — Second Brain (MOC)

Map of Content for this vault. Start here.

## Structure
- **[[FC_Barcelona_2019]]** — club overview, full squad list, key context for the season
- **Players/** — one note per player (position, nationality, shirt number, short profile)
- **Countries/** — one note per nationality, listing every player from that country

## How to use in Obsidian
1. Unzip and open the `Barcelona-2019` folder as a vault ("Open folder as vault").
2. All `[[wikilinks]]` will resolve automatically between Players, Countries, and the club note.
3. Try the **Graph View** — you'll see the club note as the central hub, countries as clusters, and players as leaf nodes.
4. Frontmatter (`country`, `position`, `shirt_number`, `born`) is queryable with the **Dataview** community plugin if you install it — e.g. list all defenders, or sort by birth year.

## Notes on scope
This covers the 2019/20 first-team squad (the "2019" era of Barça, spanning the Valverde → Setién managerial change). Add more seasons later as `FC_Barcelona_2018-19.md`, etc., and cross-link.
