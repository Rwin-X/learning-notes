# Strings Deep Dive

`🟢 EASY` #easy

## What it covers
String methods, formatting, encoding/decoding basics.

## Key points
- `.split()`, `.join()`, `.strip()`, `.replace()`
- String immutability — every "modification" creates a new string
- `bytes` vs `str`: `.encode()` / `.decode()` — this matters a LOT once you hit sockets and crypto

## Practice
Write a function that normalizes messy log lines (strip whitespace, lowercase, split fields).
