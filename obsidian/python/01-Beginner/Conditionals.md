# Conditionals

`🟢 EASY` #easy

## What it covers
`if` / `elif` / `else`, truthy/falsy values, ternary expressions.

## Key points
- Falsy values: `0`, `""`, `[]`, `{}`, `None`, `False`
- Ternary: `"even" if x % 2 == 0 else "odd"`
- `match` statement (Python 3.10+) as structural pattern matching
