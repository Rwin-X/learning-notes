# Lists and Tuples

`🟢 EASY` #easy

## What it covers
Ordered, mutable (`list`) vs immutable (`tuple`) sequences.

## Key points
- Slicing: `lst[1:4]`, `lst[::-1]` (reverse)
- List comprehensions: `[x**2 for x in range(10) if x % 2 == 0]`
- Tuples are hashable (can be dict keys), lists are not

## Practice
Parse a CSV-like line into a tuple of fields.
