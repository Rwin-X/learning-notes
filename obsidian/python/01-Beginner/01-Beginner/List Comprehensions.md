# List Comprehensions

`🟢 EASY` #easy

## What it covers
Compact syntax for building lists (and dict/set comprehensions).

## Key points
- `[expr for item in iterable if condition]`
- Dict comprehension: `{k: v for k, v in pairs}`
- Don't over-nest — past 2 levels, use a real loop for readability
