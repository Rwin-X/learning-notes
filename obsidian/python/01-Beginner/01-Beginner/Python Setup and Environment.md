# Python Setup and Environment

`🟢 EASY` #easy

## What it covers
Installing Python, using `venv`/`pipx`, choosing an editor (VS Code), and running your first script.

## Key points
- Always use a **virtual environment** per project: `python -m venv .venv`
- `pip install -r requirements.txt` for reproducible installs
- `python --version` to confirm your interpreter

## Practice
Set up a `.venv`, install `requests`, write a script that prints `sys.version`.
