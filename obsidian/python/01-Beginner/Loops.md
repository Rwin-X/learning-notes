# Loops

`🟢 EASY` #easy

## What it covers
`for`, `while`, `range()`, `break`, `continue`, `else` on loops.

## Key points
- `for item in iterable` — Python loops over **iterables**, not indices
- `enumerate()` gives index + value
- Loop `else` runs only if the loop wasn't `break`-ed — useful for search patterns

## Practice
Write a password brute-force **simulator** (not a real cracker) over a small known wordlist to internalize loop + break logic — this pattern shows up constantly in security scripting later.
