# Dictionaries and Sets

`🟢 EASY` #easy

## What it covers
Key-value mapping (`dict`) and unique collections (`set`).

## Key points
- `dict.get(key, default)` avoids `KeyError`
- Sets are perfect for **deduplication** — e.g. unique IPs in a log file
- `dict` preserves insertion order since Python 3.7

## Practice
Count word frequency in a text file using a `dict`.
