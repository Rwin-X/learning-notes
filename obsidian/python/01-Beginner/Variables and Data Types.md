# Variables and Data Types

`🟢 EASY` #easy

## What it covers
`int`, `float`, `str`, `bool`, `None`, and dynamic typing.

## Key points
- Python is dynamically typed but **strongly typed** — no silent int+str coercion
- Use `type(x)` and `isinstance(x, int)` to check types
- f-strings: `f"{name} is {age} years old"`

## Practice
Write a script that takes user input and prints its type.
