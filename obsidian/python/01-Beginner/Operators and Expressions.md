# Operators and Expressions

`🟢 EASY` #easy

## What it covers
Arithmetic, comparison, logical, and bitwise operators; operator precedence.

## Key points
- `//` floor division, `**` power, `%` modulo
- Bitwise (`&`, `|`, `^`, `~`, `<<`, `>>`) matter a lot later for **security/networking** work
- Chained comparisons: `0 < x < 10`

## Practice
Implement a simple calculator using only operators (no functions yet).
