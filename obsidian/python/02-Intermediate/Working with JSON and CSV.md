# Working with JSON and CSV

`🟡 MEDIUM` #medium

## What it covers
`json` and `csv` standard library modules for structured data.

## Key points
- `json.dumps(obj, indent=2)` for pretty output; `json.loads()` to parse
- `csv.DictReader` gives you rows as dicts keyed by header — very convenient
- Config files, API responses, and log exports are almost always JSON or CSV

## Practice
Parse a JSON API response and re-export the relevant fields as CSV.
