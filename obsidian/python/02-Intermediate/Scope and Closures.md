# Scope and Closures

`🟡 MEDIUM` #medium

## What it covers
Local/global/nonlocal scope, closures, first-class functions.

## Key points
- `global` and `nonlocal` keywords — use sparingly, they hurt readability
- A **closure** is a function that remembers variables from its enclosing scope
- Functions are objects — you can pass them around, store them in lists/dicts

## Practice
Write a closure-based counter: `make_counter()` returns a function that increments and returns a count each call.
