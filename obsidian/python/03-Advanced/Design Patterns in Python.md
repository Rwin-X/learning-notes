# Design Patterns in Python

`🟠 HARD` #hard

## What it covers
Singleton, Factory, Strategy, Observer — patterns as they actually appear in Python (often simpler than in Java/C++).

## Key points
- Python's first-class functions often replace formal Strategy/Command pattern boilerplate
- Singleton is often unnecessary — a module-level instance usually does the job
- Observer pattern shows up in event-driven GUIs (PyQt6 signals/slots — which you already use)

## Practice
Refactor a PyQt6 project's signal/slot wiring and identify which classic pattern it maps to.
