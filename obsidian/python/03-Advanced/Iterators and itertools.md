# Iterators and itertools

`🟠 HARD` #hard

## What it covers
The `itertools` module: `chain`, `product`, `permutations`, `groupby`, infinite iterators.

## Key points
- `itertools.product()` generates all combinations — the core of many brute-force/permutation tools
- `itertools.islice()` lets you slice a generator without consuming it all
- `itertools.groupby()` needs pre-sorted input to work correctly

## Practice
Use `itertools.product` to generate all 4-character alphanumeric combinations (educational demo of keyspace size, not a real cracking tool).
