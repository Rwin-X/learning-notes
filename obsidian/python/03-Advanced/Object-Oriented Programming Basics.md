# Object-Oriented Programming Basics

`🟠 HARD` #hard

## What it covers
Classes, instances, `__init__`, instance vs class attributes, `self`.

## Key points
- `self` is just a convention — it's the instance, passed automatically
- Class attributes are shared across instances; instance attributes are not
- Dunder methods (`__repr__`, `__eq__`, `__len__`) let your objects behave like built-ins

## Practice
Model a `NetworkHost` class with `ip`, `open_ports`, and a `scan()` method.
