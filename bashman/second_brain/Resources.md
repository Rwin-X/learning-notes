# Resources

> Once you've worked through the course, these are the references worth keeping close.

## Essential Resources

- **[Bash Reference Manual](https://www.gnu.org/software/bash/manual/bash.html)** — The official GNU manual — the authoritative source for every Bash feature.
- **[GNU Coreutils Manual](https://www.gnu.org/software/coreutils/manual/coreutils.html)** — Full documentation for ls, cp, mv, cat, and every other core Unix utility.
- **[ShellCheck](https://www.shellcheck.net/)** — A static analysis tool that catches common Bash scripting bugs before you run them.
- **[Bash FAQ (Greg's Wiki)](https://mywiki.wooledge.org/BashFAQ)** — Answers to the most common real-world Bash scripting questions and gotchas.
## Advanced Resources

- **[Advanced Bash-Scripting Guide](https://tldp.org/LDP/abs/html/)** — A deep, comprehensive guide covering advanced scripting techniques and edge cases.
- **[POSIX Shell Command Language Spec](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html)** — The formal specification behind sh, useful for writing portable scripts.
- **[sed & awk (O'Reilly)](https://www.oreilly.com/library/view/sed-awk/1565922255/)** — The classic reference book for mastering stream editing and text processing.
- **[Linux man-pages Project](https://man7.org/linux/man-pages/)** — The canonical source for man pages covering nearly every Linux command and syscall.
