# &&

> && runs the next command only if the previous one succeeded (exit code 0) — a compact way to chain dependent steps.

## Syntax
```bash
command1 && command2
```

## Example
```bash
$ mkdir backup && cp app.log backup/
```

## Expected output
```
(copies only if mkdir succeeded)
```

## ⚠️ Common mistake
Chaining too many && operations on one line, making failures hard to diagnose — prefer if statements for anything non-trivial.

## 💡 Practical use
Common in deployment one-liners: cd /app && git pull && ./restart.sh, where each step should only run if the last succeeded.
