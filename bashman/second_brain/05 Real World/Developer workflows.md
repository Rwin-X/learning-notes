# Developer workflows

Developers use Bash constantly outside of "real" scripting: git aliases, build shortcuts, local environment setup scripts, and quick data-wrangling one-liners while debugging.

## Example
```bash
alias gs='git status'; alias gp='git pull --rebase'
```
