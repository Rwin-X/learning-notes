# CI/CD

Nearly every CI/CD pipeline (GitHub Actions, GitLab CI, Jenkins) executes its steps as shell commands under the hood — understanding Bash means understanding what your pipeline actually does.

## Example
```bash
run: |
  npm ci
  npm test
  npm run build
```
