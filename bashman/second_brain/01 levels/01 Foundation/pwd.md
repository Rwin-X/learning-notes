# pwd

> pwd prints your current working directory — where you are right now in the filesystem tree.

## Syntax
```bash
pwd
```

## Example
```bash
$ pwd
```

## Expected output
```
/home/rwin/projects
```

## ⚠️ Common mistake
Assuming you know where you are without checking — especially before running rm or scripts with relative paths.

## 💡 Practical use
The first command to run when a script behaves unexpectedly: confirm you're actually where you think you are.
