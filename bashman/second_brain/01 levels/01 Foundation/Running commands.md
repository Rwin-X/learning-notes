# Running commands

> A command is a program name, optionally followed by arguments and flags, that you run by typing it and pressing Enter.

## Syntax
```bash
command [flags] [arguments]
```

## Example
```bash
$ echo Hello, Bash
```

## Expected output
```
Hello, Bash
```

## ⚠️ Common mistake
Forgetting that command names and flags are case-sensitive — ls and LS are not the same.

## 💡 Practical use
This is the single most repeated action in the entire course: type, Enter, read output, repeat.
