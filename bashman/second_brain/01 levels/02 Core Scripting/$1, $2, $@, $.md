# $1, $2, $@, $#

> $1, $2... refer to individual positional arguments. $@ expands to all arguments as separate words. $# gives the total argument count.

## Syntax
```bash
$1 $2 ... $@ $#
```

## Example
```bash
$ set -- alpha beta gamma
$ echo "$1 / $#/ $@"
```

## Expected output
```
alpha / 3/ alpha beta gamma
```

## ⚠️ Common mistake
Using $* instead of "$@" when looping over arguments that might contain spaces — "$@" preserves each argument as a separate word, $* does not.

## 💡 Practical use
Used to validate expected input count ([ "$#" -eq 2 ] || echo "usage: script.sh <a> <b>") in almost every CLI script.
