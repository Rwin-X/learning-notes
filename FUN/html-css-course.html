HTML و CSS را از صفر تا پیشرفته یاد بگیرید

این صفحه یک دوره کامل است: هر درس شامل توضیح ساده، کد نمونه، نتیجه زنده، اشتباه رایج و یک تمرین کوچک است. از اولین تگ HTML شروع می‌کنیم و به Grid، انیمیشن و سه پروژه کامل می‌رسیم.

بدون نیاز به دانش قبلی فقط HTML و CSS ۳ پروژه کامل
درس ۱

وب چطور کار می‌کند؟

وقتی آدرس یک سایت را در مرورگر می‌زنید، مرورگر یک درخواست به یک سرور می‌فرستد. سرور یک فایل HTML (ساختار صفحه) به همراه CSS (ظاهر صفحه) و معمولاً JavaScript (رفتار صفحه) برمی‌گرداند. مرورگر این‌ها را می‌خواند و صفحه‌ای که می‌بینید را می‌سازد.

چرا مهم است؟ HTML محتوا و معنای صفحه را مشخص می‌کند (این یک تیتر است، این یک لینک است)، و CSS نحوه نمایش آن را تعیین می‌کند (رنگ، فاصله، چیدمان). این دوره فقط روی این دو تمرکز دارد.

درس ۲

ساختار سند، Doctype، Head و Viewport

هر فایل HTML با <!DOCTYPE html> شروع می‌شود که به مرورگر می‌گوید این یک سند HTML5 است. سپس تگ <html> همه چیز را در بر می‌گیرد و شامل دو بخش است: <head> (اطلاعات پنهان مثل عنوان صفحه و متادیتا) و <body> (محتوای قابل مشاهده).

index.html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width,
                 initial-scale=1.0">
  <title>صفحه من</title>
</head>
<body>
  <h1>سلام دنیا!</h1>
</body>
</html>
نتیجه زنده

سلام دنیا!

meta charset="UTF-8" تضمین می‌کند حروف فارسی درست نمایش داده شوند. viewport (دید) باعث می‌شود صفحه در موبایل درست مقیاس شود — بدون آن، صفحه در گوشی خیلی کوچک و فشرده دیده می‌شود.

✕ اشتباه رایج
<html>
<head></head>
<body>...</body>
</html>

نبود meta charset و viewport باعث مشکلات نمایش می‌شود.

✓ روش درست
<head>
  <meta charset="UTF-8">
  <meta name="viewport" ...>
  <title>...</title>
</head>

همیشه این سه خط را در ابتدای head قرار دهید.

تمرین: یک سند خالی HTML بسازید

یک فایل بسازید که عنوان صفحه (title) آن «درباره من» باشد و در body فقط یک h1 با نام شما باشد.

<!DOCTYPE html>
<html lang="fa">
<head>
  <meta charset="UTF-8">
  <title>درباره من</title>
</head>
<body>
  <h1>نام شما</h1>
</body>
</html>
درس ۳

متن، تیترها و پاراگراف

HTML شش سطح تیتر دارد: h1 تا h6. h1 مهم‌ترین عنوان صفحه است و باید فقط یک‌بار در هر صفحه استفاده شود. پاراگراف‌ها با <p> نوشته می‌شوند.

text.html
<h1>عنوان اصلی</h1>
<h2>زیرعنوان</h2>
<p>این یک پاراگراف است که
  <strong>مهم</strong> و
  <em>تاکیدی</em> دارد.</p>

<h1>عنوان دیگر</h1>

چند h1 در یک صفحه و پرش از h1 به h4 به ساختار معنایی صفحه آسیب می‌زند.

✓ روش درست
<h1>عنوان</h1>
<h2>بخش</h2>
<h3>زیربخش</h3>

یک h1 در هر صفحه، و سطح‌ها را پله‌پله کاهش دهید.

تمرین: یک بیوگرافی کوتاه بنویسید

یک h1 با نامتان، یک h2 با عنوان «درباره من» و یک پاراگراف با دو جمله درباره خودتان بسازید؛ از strong برای یک کلمه مهم استفاده کنید.

درس ۴

لینک‌ها و تصاویر

لینک‌ها با <a href="..."> ساخته می‌شوند. تصاویر با <img src="..." alt="..."> نمایش داده می‌شوند — ویژگی alt (متن جایگزین) برای افرادی که از صفحه‌خوان استفاده می‌کنند یا تصویر بارگذاری نمی‌شود، ضروری است.

links.html
<a href="https://example.com"
   target="_blank"
   rel="noopener">
  مشاهده سایت
</a>

<img src="cat.jpg"
     alt="یک گربه نارنجی"
     width="120">
نتیجه زنده
مشاهده سایت ↗
تصویر گربه 🐱

target="_blank" لینک را در تب جدید باز می‌کند؛ همیشه آن را با rel="noopener" همراه کنید تا صفحه جدید به صفحه اصلی دسترسی نداشته باشد (مسئله امنیتی).

✕ اشتباه رایج
<img src="cat.jpg">

بدون alt، صفحه‌خوان‌ها نمی‌توانند تصویر را توصیف کنند.

✓ روش درست
<img src="cat.jpg"
     alt="گربه نارنجی روی مبل">

همیشه alt توصیفی بنویسید.

تمرین: یک لینک و یک تصویر اضافه کنید

درس ۶

تگ‌های معنایی (Semantic)

به‌جای استفاده از <div> برای همه چیز، HTML5 تگ‌هایی دارد که معنای بخش را مشخص می‌کنند: header (سربرگ)، nav (ناوبری)، main (محتوای اصلی)، section (بخش)، article (مقاله مستقل)، aside (محتوای جانبی) و footer (پاورقی).

چرا مهم است؟ تگ‌های معنایی به موتورهای جستجو و صفحه‌خوان‌ها کمک می‌کنند ساختار صفحه را بفهمند، و کد را برای توسعه‌دهندگان دیگر خواناتر می‌کند.

semantic.html
<header>
  <nav>منو</nav>
</header>
<main>
  <article>
    <h2>عنوان مقاله</h2>
    <p>متن مقاله...</p>
  </article>
  <aside>مطالب مرتبط</aside>
</main>
<footer>© ۱۴۰۴</footer>

فرم‌ها و انواع Input

فرم‌ها با <form> ساخته می‌شوند و شامل فیلدهای ورودی مثل <input>، <textarea> و <select> هستند. هر input باید یک <label> (برچسب) مرتبط داشته باشد تا کاربر بداند چه چیزی وارد کند.

form.html
<form>
  <label for="email">ایمیل</label>
  <input type="email" id="email"
         required>

  <label for="age">سن</label>
  <input type="number" id="age"
         min="0" max="120">

  <button type="submit">
    ارسال
  </button>
</form>
نتیجه زنده

اعتبارسنجی بومی (native validation) با ویژگی‌هایی مثل required (الزامی)، min/max، minlength و pattern بدون نیاز به JavaScript انجام می‌شود. مرورگر خودش پیام خطا نشان می‌دهد.

✕ اشتباه رایج
ایمیل:
<input type="text">

بدون label متصل و بدون type درست، دسترس‌پذیری و اعتبارسنجی از بین می‌رود.

✓ روش درست
<label for="e">ایمیل</label>
<input type="email" id="e">

for و id باید یکسان باشند تا کلیک روی برچسب، فوکوس را به input ببرد.

تمرین: فرم ثبت‌نام کوتاه بسازید 
<form>
  <label for="name">نام</label>
  <input type="text" id="name" required>

صوت، ویدیو، iframe و SVG درون‌خطی

تگ‌های <audio> و <video> به همراه ویژگی controls پخش‌کننده بومی مرورگر را فعال می‌کنند. <iframe> محتوای یک صفحه دیگر را درون صفحه شما نمایش می‌دهد (مثلاً نقشه یا ویدیوی یوتیوب). <svg> گرافیک برداری است که مستقیماً در HTML نوشته می‌شود.

media.html
<video controls width="240">
  <source src="clip.mp4"
          type="video/mp4">
</video>

<svg viewBox="0 0 100 100"
     width="60">
  <circle cx="50" cy="50" r="40"
          fill="currentColor"/>
</svg>

درس ۱۰

دسترس‌پذیری (Accessibility) و مبانی SEO

دسترس‌پذیری یعنی صفحه برای همه، از جمله افراد با معلولیت، قابل استفاده باشد. چند اصل پایه: همیشه alt برای تصاویر، کنتراست رنگ کافی، ترتیب منطقی تیترها، و استفاده از ویژگی‌های aria-* وقتی تگ معنایی مناسب وجود ندارد.

ویژگی ARIAکاربرد
aria-labelبرچسب نامرئی برای صفحه‌خوان
aria-hiddenپنهان کردن عنصر تزئینی از صفحه‌خوان
roleتعیین نقش عنصر (مثل role="button")

برای SEO (بهینه‌سازی برای موتورهای جستجو)، این‌ها مهم‌اند: <title> توصیفی، meta name="description"، یک h1 واحد، و متن alt معنادار روی تصاویر.

چرا مهم است؟ دسترس‌پذیری و SEO هر دو از همان پایه می‌آیند: HTML معنادار. وقتی تگ‌ها را درست استفاده کنید، هم برای انسان‌ها و هم برای ماشین‌ها (موتور جستجو، صفحه‌خوان) قابل‌فهم‌تر می‌شود.

تمرین: یک head دوستدار SEO بنویسید 
<title>فروشگاه کتاب آنلاین | کتاب‌باز</title>
<meta name="description"
      content="خرید آنلاین کتاب با ارسال سریع">
درس ۱۱

روش‌های افزودن CSS و سلکتورها

سه روش برای افزودن CSS وجود دارد: درون‌خطی (inline، با ویژگی style)، داخلی (internal، با تگ <style> در head) و خارجی (external، با فایل جدا و <link>). روش خارجی برای پروژه‌های واقعی بهترین است چون CSS از HTML جدا می‌ماند.

selectors.css
/* سلکتور تگ */
p { color: gray; }

/* سلکتور کلاس */
.card { padding: 16px; }

/* سلکتور آیدی */
#header { height: 60px; }

/* ترکیبی: فرزند مستقیم */
.card > p { margin: 0; }
نتیجه زنده

این یک کارت با سلکتور کلاس است

سلکتورها با ویرگول ترکیب می‌شوند (برای چند عنصر)، با فاصله یعنی فرزند در هر عمقی، و با > یعنی فقط فرزند مستقیم.

تمرین: سه نوع سلکتور بنویسید 
h1 { color: navy; }
.highlight { background: yellow; }
#main-title { font-size: 2rem; }
درس ۱۲

اولویت (Specificity) و ارث‌بری (Inheritance)

وقتی چند قانون CSS با یک عنصر تداخل دارند، مرورگر بر اساس اولویت تصمیم می‌گیرد کدام اعمال شود. ترتیب قدرت (از کم به زیاد): سلکتور تگ < کلاس < آیدی < style درون‌خطی < !important.

چرا مهم است؟ خیلی از باگ‌های CSS به خاطر اولویت نادرست پیش می‌آیند — استایلی که نوشته‌اید اعمال نمی‌شود چون یک سلکتور قوی‌تر در جای دیگر آن را بازنویسی می‌کند.

specificity.css
p { color: blue; }
.note { color: green; }
#warn { color: red; }

/* #warn برنده می‌شود چون
   آیدی از کلاس قوی‌تر است */
نتیجه زنده

این متن قرمز است

ارث‌بری یعنی بعضی ویژگی‌ها (مثل color و font-family) به‌طور خودکار از والد به فرزند منتقل می‌شوند، اما ویژگی‌های جعبه‌ای (مثل margin و border) ارث‌بری نمی‌شوند.

✕ اشتباه رایج
.btn { color: red !important; }
#submit { color: blue; }

استفاده زیاد از !important دیباگ کردن را سخت می‌کند.

✓ روش درست
.btn { color: red; }
.btn--primary { color: blue; }

از کلاس‌های دقیق‌تر به‌جای !important استفاده کنید.

درس ۱۳

مدل جعبه (Box Model)

هر عنصر HTML یک جعبه مستطیلی است که از چهار لایه تشکیل شده: content (محتوا)، padding (فاصله داخلی)، border (حاشیه) و margin (فاصله خارجی).

box.css
.box {
  box-sizing: border-box;
  width: 160px;
  padding: 16px;
  border: 3px solid #2d6a4f;
  margin: 10px;
}
نتیجه زنده
محتوا

box-sizing: border-box باعث می‌شود padding و border داخل عرض/ارتفاع تعریف‌شده حساب شوند، نه اضافه بر آن — این باعث می‌شود چیدمان‌ها قابل پیش‌بینی‌تر باشند.

✕ اشتباه رایج
.box {
  width: 200px;
  padding: 20px;
  /* عرض واقعی: 240px! */
}
✓ روش درست
* { box-sizing: border-box; }
.box { width: 200px; padding: 20px; }
/* عرض واقعی: دقیقاً 200px */
تمرین: یک جعبه با حاشیه گرد بسازید 
.box {
  box-sizing: border-box;
  padding: 20px;
  border: 2px dashed gray;
  border-radius: 12px;
}
درس ۱۴

واحدها (Units)

px واحد مطلق (پیکسل ثابت) است. rem نسبت به اندازه فونت ریشه (معمولاً ۱۶px) است و برای تایپوگرافی ریسپانسیو بهترین انتخاب است. em نسبت به فونت والد است. %، vw و vh نسبت به والد یا اندازه صفحه نمایش هستند.

واحدنسبت بهکاربرد پیشنهادی
pxمقدار ثابتborder، سایه
remفونت ریشه (html)فونت، فاصله‌گذاری
emفونت والد مستقیمفاصله داخل یک کامپوننت
%اندازه والدعرض ستون‌ها
vw/vhعرض/ارتفاع صفحهسکشن‌های تمام‌صفحه
units.css
html { font-size: 16px; }
.title { font-size: 1.5rem; } /* 24px */
.hero { min-height: 60vh; }
نتیجه زنده
عنوان با rem
✕ اشتباه رایج
p { font-size: 16px; }
h1 { font-size: 32px; }

فونت با px به تنظیمات دسترس‌پذیری مرورگر کاربر واکنش نشان نمی‌دهد.

✓ روش درست
p { font-size: 1rem; }
h1 { font-size: 2rem; }

با rem، اگر کاربر فونت پیش‌فرض مرورگر را بزرگ کند، همه چیز متناسب بزرگ می‌شود.

تمرین: با rem و vh کار کنید 
.section { min-height: 100vh; padding: 2rem; }
.heading { font-size: 2.5rem; }

رنگ‌ها، گرادیان و سایه

رنگ را می‌توان با نام (tomato)، هگز (#2d6a4f)، rgb()، hsl() یا فرمت جدیدتر oklch() تعریف کرد. hsl (رنگ، اشباع، روشنی) برای ساخت تم‌های رنگی مرتبط راحت‌تر از هگز است.

colors.css
.a { background: hsl(152 40% 30%); }
.b {
  background: linear-gradient(135deg,
    #2d6a4f, #74c69d);
}

شبه‌کلاس‌ها و شبه‌عنصرها

شبه‌کلاس (مثل :hover) حالت خاصی از یک عنصر موجود را هدف می‌گیرد. شبه‌عنصر (مثل ::before) محتوای مجازی جدیدی می‌سازد که در DOM واقعی وجود ندارد.

.btn:hover { background: #1e4d38; }

  color: var(--accent);
}
نتیجه زنده (موس را روی دکمه ببرید)

</style>

قدم بعدی: به کجا بروم؟

با تسلط بر HTML و CSS، پایه محکمی برای ساخت هر نوع صفحه وب دارید. قدم بعدی منطقی، یادگیری JavaScript است — زبانی که به صفحات شما رفتار و تعامل واقعی (مثل پاسخ به کلیک، ارسال فرم بدون رفرش، یا بارگذاری داده) می‌دهد. این دوره عمداً JavaScript را پوشش نداد تا تمرکز کامل روی پایه HTML/CSS باشد.

پیشنهاد مسیر یادگیری: پس از JavaScript پایه، می‌توانید به سراغ یک فریم‌ورک مثل React یا Vue بروید، یا اگر به طراحی علاقه بیشتری دارید، عمیق‌تر در انیمیشن‌های پیشرفته CSS و ابزارهایی مثل Sass/Tailwind غرق شوید.

دوره کامل HTML و CSS — ساخته‌شده فقط با HTML و CSS، بدون حتی یک خط جاوااسکریپت.
