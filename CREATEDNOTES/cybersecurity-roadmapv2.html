cybersecurity roadmap

A linear path from computing fundamentals to specialization — networking and systems first, then defensive skill, then offense, then a chosen track. Each stage lists the branches worth studying in parallel.

core stage skill branch optional / specialization
stages 7 format sequential, branch in parallel status foundation → specialization
STAGE 01 / FOUNDATION

Computing & Networking Basics required before anything else

You cannot secure what you don't understand. This stage builds the mental model of how machines, networks, and operating systems actually behave.

NetworkingCORE
  • OSI & TCP/IP models
  • IP addressing, subnetting, DNS, DHCP
  • TCP vs UDP, ports, common protocols
  • Routing & switching basics
Operating SystemsCORE
  • Linux fundamentals & shell (bash)
  • Windows internals & Active Directory basics
  • File systems, permissions, processes
  • Package management, services
ProgrammingCORE
  • Python for scripting & automation
  • Bash scripting
  • Reading C (for exploit & malware analysis later)
STAGE 02 / FOUNDATION

Security Fundamentals concepts & vocabulary

The shared language of the field — CIA triad, risk, threat modeling, cryptography basics. This is what certifications like Security+ formalize.

Core ConceptsCORE
  • CIA triad, AAA, defense in depth
  • Threats, vulnerabilities, risk vs exposure
  • Security policies & compliance basics
CryptographyCORE
  • Symmetric vs asymmetric encryption
  • Hashing, salting, digital signatures
  • TLS/SSL handshake, PKI & certificates
Certification trackOPT
  • CompTIA Security+
  • CompTIA Network+ (if networking is weak)
CHECKPOINT — you should now be able to
explain how a packet travels from your machine to a server, set up a basic Linux box, and describe the CIA triad without notes.
STAGE 03 / DEFENSIVE

Defensive Security (Blue Team) detect, monitor, respond

Understanding defense before offense makes offense meaningful. This is also where most entry-level jobs live.

MonitoringCORE
  • SIEM tools (Splunk, ELK, Wazuh)
  • Log analysis & correlation
  • IDS / IPS (Snort, Suricata)
Incident ResponseCORE
  • IR lifecycle (prepare → contain → eradicate → recover)
  • Digital forensics basics
  • Malware analysis fundamentals
HardeningCORE
  • System & network hardening baselines
  • Firewalls, segmentation, least privilege
  • Patch & vulnerability management
STAGE 04 / OFFENSIVE

Offensive Security (Red Team) think like the attacker

Ethical hacking — same techniques as attackers, used with authorization to find weaknesses before they do.

ReconnaissanceCORE
  • OSINT techniques & tools
  • Nmap & service enumeration
  • Passive vs active recon
ExploitationCORE
  • Vulnerability scanning (Nessus, OpenVAS)
  • Metasploit fundamentals
  • Manual exploitation basics
Web ApplicationCORE
  • OWASP Top 10
  • Burp Suite workflow
  • SQLi, XSS, SSRF, auth flaws
Certification trackOPT
  • CEH
  • eJPT (practical alternative)
CHECKPOINT — you should now be able to
run a full recon-to-report cycle on a lab target (TryHackMe / HTB machine) and explain each finding's real-world impact.
STAGE 05 / APPLIED

Hands-On Practice where theory becomes skill

None of the above sticks without repetition against real targets. This stage runs in parallel with 03–04, not after them.

LabsCORE
  • TryHackMe learning paths
  • HackTheBox machines & challenges
  • Home lab (VMs, pfSense, vulnerable VMs)
CTFsCORE
  • picoCTF for beginners
  • Weekend CTFs (CTFtime.org)
  • Category focus: web, crypto, forensics, pwn
Build & documentCORE
  • Write your own tools (scanners, parsers)
  • Publish writeups & a GitHub portfolio
  • Keep a lab notebook of what broke and why
STAGE 06 / SPECIALIZATION

Pick a Track go deep in one direction

Generalist knowledge gets you hired at junior level; depth in one track is what moves you up. Pick based on what you enjoyed most in stages 3–5.

Penetration TestingTRACK
  • Advanced Burp / manual web exploitation
  • Active Directory attacks
  • OSCP
Threat Intel & SOCTRACK
  • MITRE ATT&CK framework
  • Threat hunting methodology
  • GCIH / Security Blue Team certs
Malware AnalysisTRACK
  • Static & dynamic analysis
  • Reverse engineering (Ghidra, x64dbg)
  • Sandboxing & behavioral analysis
Cloud SecurityTRACK
  • AWS / Azure security fundamentals
  • IAM misconfig & container security
  • AZ-500 / AWS Security Specialty
STAGE 07 / CAREER

Portfolio & Entry turn skill into a role

The last mile — making everything above legible to someone who has to decide whether to hire you.

Proof of workCORE
  • GitHub with real, documented tools
  • CTF / HTB rank as evidence of skill
  • Blog or writeups explaining your thinking
Entry pointsCORE
  • SOC analyst (tier 1)
  • IT / sysadmin roles as a stepping stone
  • Bug bounty as supplementary proof
path: foundation → defense → offense → specialization → career rev. 2026
