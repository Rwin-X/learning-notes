> Cybersecurity Learning Roadmap

A staged path from computing fundamentals to offensive and defensive security specialization — sequenced so each stage unlocks the next. Built around CEH and CompTIA Security+ as the two certification checkpoints.

Foundation
Computing & OS Fundamentals
4–6 weeks

Everything above this breaks without it. You need to be comfortable inside both Linux and Windows before any security concept means much.

Linux fundamentals
Filesystem hierarchy, permissions, processes, package managers, bash scripting
Windows internals
Registry, services, Active Directory basics, PowerShell
Networking basics
TCP/IP, OSI model, subnetting, DNS, DHCP, routing
Programming literacy
Python for scripting, plus reading C to understand memory-level bugs later

Foundation
Networking & Protocol Deep Dive
4–6 weeks

Nearly every attack and defense technique is a networking concept in disguise. This stage is what makes packet captures readable instead of noise.

Packet analysis
Wireshark, tcpdump, reading captures at the byte level
Core protocols
HTTP/S, DNS, SMB, FTP, SSH, ARP — how each is abused
Network devices
Firewalls, routers, switches, VLANs, NAT, VPNs
Network monitoring
IDS/IPS concepts, netflow, baseline traffic analysis

can trace a full TCP handshake and explain a pcap without notes

Offensive Track
Ethical Hacking & Penetration Testing
8–12 weeks

The methodical attacker's mindset — reconnaissance through reporting. This is where the CEH curriculum lives, and where hands-on labs matter more than reading.

Recon & footprinting
OSINT, Shodan, DNS enumeration, Nmap scanning
Vulnerability scanning
Nessus, OpenVAS, manual verification of findings
Exploitation
Metasploit, manual exploit development basics, privilege escalation
Web app security
OWASP Top 10, Burp Suite, SQLi, XSS, auth bypass
Post-exploitation
Persistence, lateral movement, pivoting
Reporting
Writing findings a non-technical client can act on

Checkpoint 02 — Certification
Certified Ethical Hacker (CEH)
6–10 weeks

Formalizes the offensive methodology from stage 02 into a recognized credential — attacker tools, techniques, and the legal/ethical framework around using them.

Attack lifecycle
Formal phases: recon → gain access → maintain access → cover tracks
Tool proficiency
Standardized toolkit knowledge across the CEH blueprint
Legal & ethical framework
Scope, authorization, rules of engagement

Defensive Track
Blue Team, Detection & Incident Response
8–10 weeks

Understanding attacks is only half the value — knowing how to detect and respond to them is what makes the offensive knowledge operational rather than academic.

SIEM & log analysis
Splunk, ELK stack, correlating events across sources
Threat detection
Building detection rules, MITRE ATT&CK mapping
Incident response
IR lifecycle, containment, eradication, recovery
Digital forensics
Disk/memory forensics, chain of custody, Autopsy/Volatility
Malware analysis
Static/dynamic analysis basics, sandboxing
