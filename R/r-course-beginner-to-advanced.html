BEGINNER

01R چیست و چرا متفاوت استmental model

زبان R در اصل برای تحلیل آماری طراحی شده، نه برای برنامه‌نویسی عمومی. همین ریشه باعث شده چند مفهوم پایه با زبان‌های دیگری که شاید پیش‌تر دیده باشید، تفاوت داشته باشد.

همه‌چیز وکتور استvectorized

حتی یک عدد تکی در R یک وکتور به طول یک است. عملیات روی وکتورها به‌صورت عنصر‌به‌عنصر انجام می‌شود، بدون نیاز به حلقه‌ی دستی.

شمارش از یک آغاز می‌شود1-indexed

برخلاف بسیاری از زبان‌های برنامه‌نویسی، نخستین عضو یک وکتور با x[1] به‌دست می‌آید، نه x[0].

عملگر انتساب assignment

علامت رایج برای انتساب مقدار، پیکان چپ (<-) است. علامت مساوی نیز کار می‌کند، اما در میان برنامه‌نویسان R رایج‌تر نیست.

مقدار گم‌شده بخشی از زبان استNA

مقدار NA نشان‌دهنده‌ی داده‌ی گم‌شده است و یک شهروند درجه‌یک در زبان به‌شمار می‌رود، نه یک استثنا.

اگر از پایتون می‌آیید وکتور در R از نظر رفتار به numpy.array نزدیک‌تر است تا لیست پایتون. data.frame معادل pandas.DataFrame است، و بسته‌ی tidyverse همان روحیه‌ی pandas و matplotlib را دارد، با این تفاوت که از عملگر pipe به‌جای زنجیره‌ی متدها استفاده می‌کند.

04وکتور، ستون فقرات زبان Rvectors

تقریباً تمام عملیات عددی در زبان R حول محور وکتور می‌چرخد. درک درست این بخش، پایه‌ی فهم درست بقیه‌ی زبان است.

vectors.R
# creating a vector with c() -- combine
v <- c(10, 20, 30, 40)

# numeric sequences
1:10              # 1 2 3 ... 10
seq(0, 1, by=0.25)
seq(1, 10, length.out=5)

# repetition
rep(c(1,2), times=3)   # 1 2 1 2 1 2
rep(c(1,2), each=3)    # 1 1 1 2 2 2

# operating on the whole vector, no loop needed
v * 2          # 20 40 60 80
v + c(1,1,1,1) # element-wise sum
v > 25         # TRUE/FALSE for each element

# statistics over a vector
sum(v); mean(v); max(v); min(v); length(v); sd(v)
بازچرخانی وکتور (recycling) اگر دو وکتور با طول متفاوت را با هم جمع کنید، R وکتور کوتاه‌تر را به‌صورت خودکار تکرار می‌کند تا طول هر دو برابر شود، بدون آن‌که خطایی صادر شود (گاهی فقط یک هشدار نمایش داده می‌شود). این رفتار می‌تواند منشأ خطاهای پنهان باشد، پس همیشه طول وکتورها را بررسی کنید.
recycling-example.R
c(1,2,3,4) + c(10,20)
# result: 11 22 13 24 -- the second vector repeated twice

05ایندکس‌گذاری و زیرمجموعه‌گیریindexing & subsetting

سه روش اصلی برای دسترسی به عناصر وجود دارد: بر اساس موقعیت عددی، بر اساس نام، و بر اساس شرط منطقی. روش سوم پرکاربردترین روش در تحلیل داده است.

indexing.R
v <- c(a=5, b=10, c=15, d=20)

v[1]          # first element (indexing starts at 1)
v[c(1,3)]     # first and third elements
v[-1]         # everything except the first -- negative means drop
v["b"]        # access by name
v[v > 10]     # logical filter -- only elements passing the condition

# replacement uses the same syntax
v[v > 10] <- 0   # zero out every element greater than 10
عملگرنحوکاربرد
براکت تکیx[i]زیرمجموعه می‌گیرد، نوع ساختار اصلی حفظ می‌شود
براکت دوتاییx[[i]]یک عضو را از فهرست استخراج می‌کند، بدون بسته‌بندی
علامت دلارx$nameدسترسی به ستون یا فیلد با نام، در فهرست و قاب داده
تفاوت [ ] و [[ ]] در فهرست دستور list[1] یک زیرفهرست با یک عضو برمی‌گرداند که خود همچنان از نوع فهرست است. دستور list[[1]] محتوای همان عضو را بدون بسته‌بندی برمی‌گرداند. این تفاوت شبیه تفاوت میان برش (slice) و دسترسی تکی در پایتون است، با این تفاوت که در R نوع خروجی را نیز تغییر می‌دهد.

add <- function(a, b=10) {

add(5, 2)     # 7
add(b=1, a=2) # named arguments -- order doesn't matter

12برنامه‌نویسی شیءگراS3 & S4

زبان R چند سامانه‌ی شیءگرایی دارد. دو سامانه‌ی رایج S3 و S4 نام دارند. S3 ساده و غیررسمی است؛ S4 رسمی‌تر است و اعتبارسنجی نوع را نیز انجام می‌دهد.

سامانه‌ی S3 informal OOP

# a constructor function returning a list with a class attribute
new_animal <- function(name, sound) {
  obj <- list(name = name, sound = sound)
  class(obj) <- "animal"
  obj
}

# a generic function and its method for class "animal"
speak <- function(x) UseMethod("speak")
speak.animal <- function(x) {
  cat(x$name, "says", x$sound, "\n")
}

cat_obj <- new_animal("Cat", "Meow")
speak(cat_obj)   # Cat says Meow

سامانه‌ی S4 formal OOP

setClass("Animal", representation(
  name = "character",
  sound = "character"
))

setGeneric("speak", function(x) standardGeneric("speak"))
setMethod("speak", "Animal", function(x) {
  cat(x@name, "says", x@sound, "\n")
})

dog <- new("Animal", name="Dog", sound="Woof")

صدور و دریافت خطا condition system

safe_divide <- function(a, b) {
  if (b == 0) {
    stop("division by zero is not allowed")
  }
  a / b
}

# tryCatch intercepts errors, warnings and messages
result <- tryCatch({
  safe_divide(10, 0)
}, error = function(e) {
  cat("caught an error:", conditionMessage(e), "\n")
  NA
})

# slow: growing a vector inside a loop reallocates memory each time

  result <- c(result, i^2)
}

# fast: pre-allocate, or better, vectorize entirely
result <- (1:100000)^2
