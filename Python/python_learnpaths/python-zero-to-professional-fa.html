پایتون یک زبان تفسیری است: برنامه‌ای به‌نام مفسر کد را می‌خواند و اجرا می‌کند. دو راه اصلی برای اجرا داری: REPL (تایپ python3 در ترمینال) برای آزمایش سریع، و اسکریپت (فایل .py) برای هر چیزی که می‌خواهی ذخیره و دوباره اجرا کنی.

چرا مهم است؟

تمام تمرین‌های این دوره فرض می‌کنند بتوانی کد اجرا کنی. تفاوت «تایپ در REPL» و «نوشتن فایل و اجرای آن» جلوی سردرگمی‌های اولیه را می‌گیرد.

مدل ذهنی

REPL مثل کاغذ یادداشت است: هر عبارت را فوری اجرا می‌کند ولی چیزی ذخیره نمی‌شود. اسکریپت یک دستورالعمل نوشته‌شده است که مفسر از بالا تا پایین می‌خواند.

مدل ذهنی

در پایتون متغیر جعبه‌ای که مقدار را نگه می‌دارد نیست؛ برچسبی است که به یک شیء در حافظه چسبیده. x = 5 شیء 5 را می‌سازد و برچسب x را به آن می‌چسباند. y = x برچسب دومی روی همان شیء می‌چسباند، نه کپی.

پیش‌بینی خروجی

خروجی چیست؟ a = 10 سپس b = a سپس a = 20 و print(b)

چیست؟

شناسه (نام متغیر، تابع و...) باید با حرف یا زیرخط شروع شود، فقط حرف/عدد/زیرخط داشته باشد، و کلمه‌ی کلیدی رزرو (if، for، class، ...) نباشد.

چرا مهم است؟

نام‌گذاری یکدست طبق PEP 8 ارزان‌ترین راه برای خواناکردن کد برای هر توسعه‌دهنده دیگر (و خودت در آینده) است.

نحو و مثال
python

اشتباه رایج

نام‌گذاری با کلمه‌ی کلیدی (class) یا شروع با عدد (1st_place) و نیز overshadow‌کردن نام‌های داخلی مثل list و str.

راه‌حل درست

از first_place استفاده کن و نام‌های built-in را دوباره‌تعریف نکن. قرارداد: snake_case برای متغیر/تابع، PascalCase برای کلاس، UPPER_CASE برای ثابت.

اصلاح کد

کدام نامعتبرند: 2fast، _secret، my-var، class، total_1؟

چیست؟

نحو و مثال

چرا None جداست؟

None با 0، رشته‌ی خالی یا False فرق دارد: یعنی «هیچ مقداری تنظیم نشده». تابعی که return ندارد، خودکار None برمی‌گرداند.

چیست؟

چرا مهم است؟

Truthiness

سیستم کتابخانه: dataclass به‌نام Book (title, author, available) و کلاس Library با متدهای checkout(title) و return_book(title) که پیام مناسب چاپ کنند.

library.py
from dataclasses import dataclass

@dataclass
class Book:
    title: str
    author: str
    available: bool = True

class Library:
    def __init__(self, books):
        self.books = books

    def _find(self, title):
        return next((b for b in self.books if b.title == title), None)

    def checkout(self, title):
        book = self._find(title)
        if book is None:
            print(f"'{title}' not found")
        elif not book.available:
            print(f"'{title}' is already checked out")
        else:
            book.available = False
            print(f"Checked out '{title}'")

    def return_book(self, title):
        book = self._find(title)
        if book:
            book.available = True
            print(f"Returned '{title}'")

lib = Library([Book("Dune", "Herbert")])
lib.checkout("Dune")
lib.checkout("Dune")
lib.return_book("Dune")

from pathlib import Path

class EmptyFileError(Exception):
    pass

def count_nonempty_lines(path):
    file_path = Path(path)
    if not file_path.exists():
        raise FileNotFoundError(f"No such file: {path}")
    with open(file_path) as f:
        lines = [line for line in f if line.strip()]
    if not lines:
        raise EmptyFileError(f"{path} has no non-empty lines")
    return len(lines)

try:
    print(count_nonempty_lines("notes.txt"))
except (FileNotFoundError, EmptyFileError) as e:
    print(f"Error: {e}")

from functools import wraps

def retry(times=3):
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            last_error = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_error = e
                    print(f"Attempt {attempt} failed: {e}")
            raise last_error
        return wrapper
    return decorator

@retry(times=3)
def flaky():
    raise ValueError("simulated failure")

نحو و مثال

import os, time, requests

def get_with_retries(url, headers, max_attempts=3):
    for attempt in range(1, max_attempts + 1):
        try:
            r = requests.get(url, headers=headers, timeout=5)
            if r.status_code == 200:
                return r.json()
            if r.status_code == 429:          # محدودیت نرخ
                time.sleep(2 ** attempt)
                continue
            r.raise_for_status()
        except requests.exceptions.RequestException as e:
            print(f"Attempt {attempt} failed: {e}")
    return None

چرا مهم است؟

راه‌حل درست

طراحی راه‌حل

باید (الف) ۱۰٬۰۰۰ تصویر را ریسایز و (ب) ۱۰٬۰۰۰ URL را دانلود کنی. برای هرکدام چه ابزاری؟

(الف) CPU-محور ← multiprocessing. (ب) I/O-محور ← asyncio یا threading.

چیست؟

async def یک coroutine تعریف می‌کند. await (فقط داخل coroutine) آن را در نقطه‌ی انتظار I/O متوقف می‌کند و به event loop اجازه می‌دهد coroutine دیگری را اجرا کند.

چرا مهم است؟

await دقیقاً نقاطی را نشان می‌دهد که coroutine حاضر به توقف است. event loop فقط در await صریح می‌تواند سراغ کار دیگری برود؛ استدلال درباره‌ی حالت مشترک بسیار ساده‌تر از threadهاست که ممکن است تقریباً در هر دستور عوض شوند.

نحو و مثال
python
import asyncio

async def fetch_page(name, delay):
    print(f"Start fetching {name}")
    await asyncio.sleep(delay)      # شبیه‌سازی انتظار شبکه
    print(f"Finished fetching {name}")
    return name

async def main():
    results = await asyncio.gather(
        fetch_page("A", 2),
        fetch_page("B", 1),
    )
    print(results)

asyncio.run(main())

مسدودکردن داخل کد async: صدازدن تابع کند همزمان (مثل time.sleep() یا requests) داخل coroutine، که کل event loop و همه‌ی کارهای هم‌زمان را منجمد می‌کند.

راه‌حل درست

چرا B زودتر تمام می‌شود

هر دو coroutine بلافاصله با gather شروع می‌شوند؛ B فقط ۱ ثانیه منتظر است پس زودتر تمام می‌شود، با اینکه A زودتر شروع شده.

پیش‌بینی خروجی

اگر همین دو کار را ترتیبی با time.sleep() اجرا کنی، کل زمان نسبت به gather چقدر می‌شود؟

ترتیبی: حدود ۳ ثانیه (۲+۱). با gather: حدود ۲ ثانیه؛ زمان کل تقریباً برابر طولانی‌ترین انتظار تکی است نه مجموع.

چیست؟

کاری I/O-bound است که بیشتر زمانش منتظر چیزی بیرونی (شبکه، دیسک، فرآیند دیگر) باشد، و CPU-bound است که بیشتر زمانش واقعاً محاسبه روی CPU باشد. این تشخیص تعیین می‌کند کدام ابزار واقعاً کمک می‌کند.

چرا مهم است؟

همزمانی با thread یا asyncio روی مسئله‌ی CPU-محور فایده ندارد (انتظاری برای هم‌پوشانی نیست و GIL هم جلوی موازی‌شدن را می‌گیرد). multiprocessing برای مسئله‌ی سبک I/O-محور فقط پیچیدگی و سربار راه‌اندازی process می‌افزاید.

گام‌به‌گام
  • کار requests صدا می‌زند، دیتابیس می‌خواند یا فایل بزرگ می‌خواند؟ احتمالاً I/O-bound ← asyncio/threading.
  • کار محاسبات سنگین یا پردازش تصویر/ویدیو بدون انتظار بیرونی دارد؟ احتمالاً CPU-bound ← multiprocessing.
  • مطمئن نیستی؟ اول اندازه بگیر (profile)؛ گاهی راه‌حل واقعی الگوریتم بهتر است نه همزمانی.

بخش [project.scripts] یعنی بعد از نصب، تایپ myapp در ترمینال تابع main در myapp/cli.py را اجرا می‌کند؛ ابزارهای خط‌فرمان نصب‌شده با pip دقیقاً همین‌طور کار می‌کنند.

CATEGORIES = {".jpg": "images", ".png": "images", ".pdf": "documents", ".txt": "documents", ".mp3": "audio"}

def classify(path):
    return CATEGORIES.get(path.suffix.lower(), "other")

def plan_moves(folder):
    return [(p, Path(folder) / classify(p) / p.name) for p in Path(folder).iterdir() if p.is_file()]

def apply_moves(moves, dry_run=True):
    for src, dst in moves:
        if dry_run:
            print(f"Would move: {src.name} -> {dst}")
        else:
            dst.parent.mkdir(parents=True, exist_ok=True)
            src.rename(dst)

apply_moves(plan_moves("downloads"), dry_run=True)

import re
from collections import Counter

LINE = re.compile(r"(GET|POST) (\S+) (\d{3})")

def parse_log(path):
    statuses, paths = Counter(), Counter()
    with open(path) as f:
        for line in f:
            m = LINE.search(line)
            if not m:
                continue
            _, request_path, status = m.groups()
            statuses[status] += 1
            paths[request_path] += 1
    return statuses, paths

statuses, paths = parse_log("access.log")
print("Status codes:", dict(statuses))
print("Top paths:", paths.most_common(3))

import json

class Contact:
    def __init__(self, name, email):
        self.name = name
        self.email = email

    @property
    def email(self):
        return self._email

    @email.setter
    def email(self, value):
        if "@" not in value:
            raise ValueError(f"Invalid email: {value}")
        self._email = value

    def to_dict(self):
        return {"name": self.name, "email": self.email}

class AddressBook:
    def __init__(self):
        self.contacts = []

    def add(self, name, email):
        self.contacts.append(Contact(name, email))

    def find(self, name):
        return [c for c in self.contacts if name.lower() in c.name.lower()]

    def save(self, path):
        with open(path, "w") as f:
            json.dump([c.to_dict() for c in self.contacts], f, indent=2)

import json
from functools import wraps
from pathlib import Path

NOTES_FILE = Path("notes.json")

def autosave(method):
    @wraps(method)
    def wrapper(self, *args, **kwargs):
        result = method(self, *args, **kwargs)
        self.save()
        return result
    return wrapper

class NotesApp:
    def __init__(self):
        self.notes = json.loads(NOTES_FILE.read_text()) if NOTES_FILE.exists() else []

    def save(self):
        NOTES_FILE.write_text(json.dumps(self.notes, indent=2))

    @autosave
    def add(self, text):
        self.notes.append(text)

    @autosave
    def delete(self, index):
        del self.notes[index]

    def search(self, keyword):
        return (n for n in self.notes if keyword.lower() in n.lower())

import json
import requests
from pathlib import Path

DATA_FILE = Path("collected.json")

def fetch_repo_stats(repo):
    r = requests.get(f"https://api.github.com/repos/{repo}", timeout=5)
    r.raise_for_status()
    d = r.json()
    return {"repo": repo, "stars": d["stargazers_count"], "forks": d["forks_count"]}

def append_result(record):
    existing = json.loads(DATA_FILE.read_text()) if DATA_FILE.exists() else []
    existing.append(record)
    DATA_FILE.write_text(json.dumps(existing, indent=2))

try:
    record = fetch_repo_stats("python/cpython")
    append_result(record)
    print(f"Collected: {record}")
except requests.exceptions.RequestException as e:
    print(f"Fetch failed: {e}")

            return url, resp.status

    async with aiohttp.ClientSession() as session:
        return await asyncio.gather(*(check_url(session, u) for u in urls))

def normalize_whitespace(text: str) -> str:
    """Collapse runs of whitespace into single spaces and strip ends."""

    """Convert text into a lowercase, hyphen-separated slug."""
    text = re.sub(r"[^\w\s-]", "", text.lower().strip())
    return re.sub(r"[\s_]+", "-", text)

from pathlib import Path

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")
logger = logging.getLogger(__name__)

ALLOWED_DIR = Path("workspace").resolve()

def resolve_safe_path(user_filename):
    target = (ALLOWED_DIR / user_filename).resolve()
    if not target.is_relative_to(ALLOWED_DIR):
        raise ValueError(f"Path escapes allowed directory: {user_filename}")
    return target

def convert_file(user_filename):
    target = resolve_safe_path(user_filename)
    if not target.exists():
        raise FileNotFoundError(target)
    logger.info(f"Converting file: {target.name}")
    result = subprocess.run(["gzip", "-k", str(target)], capture_output=True, text=True, timeout=30)
    if result.returncode != 0:
        logger.error(f"Conversion failed for {target.name}")
    return result.returncode == 0

from datetime import datetime

def add_task(conn, title, priority, due_date):
    with conn:
        conn.execute("INSERT INTO tasks (title, priority, due_date) VALUES (?, ?, ?)", (title, priority, due_date))

def complete_task(conn, task_id):
    with conn:
        conn.execute("UPDATE tasks SET done = 1 WHERE id = ?", (task_id,))

def list_open_tasks(conn):
    return conn.execute("SELECT id, title, priority, due_date FROM tasks WHERE done = 0 ORDER BY due_date").fetchall()

def save_snapshot(conn, value):
    with conn:
        conn.execute("INSERT INTO snapshots (fetched_at, value) VALUES (?, ?)", (datetime.now().isoformat(timespec="minutes"), value))

def build_report(conn):
    tasks = list_open_tasks(conn)
    latest = conn.execute("SELECT fetched_at, value FROM snapshots ORDER BY id DESC LIMIT 1").fetchone()
    lines = [f"PulseOps report — {datetime.now():%Y-%m-%d}", "", f"Open tasks: {len(tasks)}"]
    for _, title, priority, due in tasks:
        lines.append(f"  [{priority}] {title} (due {due})")
    lines.append(f"\nLatest snapshot: {latest[1]} (fetched {latest[0]})" if latest else "\nNo snapshots fetched yet.")
    return "\n".join(lines)

SQLite برای مقیاس یک ابزار شخصی (هزاران وظیفه و snapshot) بدون هیچ تنظیم ویژه‌ای کافی است. اگر list_open_tasks روی داده‌ی خیلی بزرگ‌تر بسیار زیاد صدا زده شد، اولین بهینه‌سازی ایندکس روی (done, due_date) است؛ فقط وقتی profile نشان داد لازم است، نه از قبل.

چک‌لیست مستندات

README (کار ابزار، نصب، یک مثال از هر فرمان)؛ .env.example با تمام متغیرهای محیطی و مقادیر نمونه‌ی امن؛ docstring روی هر تابع عمومی؛ بخش «معماری» در README مطابق CAP.1.

گسترش

اجرای زمان‌بندی‌شده (cron یا Task Scheduler) فرمان pulseops fetch برای ساخت تاریخچه‌ی واقعی، و گزینه‌ی --format json برای گزارش.
