The Complete Python HTTP Requests Guide

Everything you need to make HTTP requests in Python — from a single GET call to sessions, retries, streaming, async clients, and the raw urllib standard library. Full of runnable examples.

requests httpx aiohttp urllib Python 3.9+

1. Installation

The requests library is the de facto standard for HTTP in Python. It is not part of the standard library, so install it first.

# Install requests
pip install requests

# Optional: async-capable HTTP client (sync + async in one API)
pip install httpx

# Optional: fully async client, popular for high-concurrency scraping
pip install aiohttp

# Optional: automatic retries with backoff (used later in this guide)
pip install urllib3
Tip: Use a virtual environment (python -m venv venv) so these packages don't pollute your system Python.

2. requests vs urllib (stdlib)

LibraryBuilt-in?Ease of useAsync supportBest for

This guide leads with requests since it covers almost every use case you'll hit as a developer, then covers httpx/aiohttp for async work and urllib for when you can't install anything.

3. GET Requests GET

GET retrieves data from a server. It should never modify server state.

Basic GET

import requests

response = requests.get("https://api.github.com/users/octocat")

print(response.status_code)   # 200
print(response.json())          # parsed JSON as a dict
print(response.headers["Content-Type"])

GET with query parameters

Pass a dict via params — requests handles URL encoding for you.

import requests

params = {
    "q": "python http requests",
    "sort": "stars",
    "order": "desc",
    "per_page": 5,
}

response = requests.get("https://api.github.com/search/repositories", params=params)
data = response.json()

for repo in data["items"]:
    print(repo["full_name"], "-", repo["stargazers_count"])

# Requests built this URL automatically:
print(response.url)
# https://api.github.com/search/repositories?q=python+http+requests&sort=stars&order=desc&per_page=5

GET with custom headers

import requests

headers = {
    "User-Agent": "my-app/1.0",
    "Accept": "application/json",
}

response = requests.get("https://api.github.com/repos/psf/requests", headers=headers)
print(response.json()["description"])

List of duplicate query keys

Some APIs expect repeated keys, e.g. ?tag=a&tag=b. Pass a list as the value.

import requests

params = {"tag": ["python", "networking", "http"]}
response = requests.get("https://httpbin.org/get", params=params)
print(response.url)
# https://httpbin.org/get?tag=python&tag=networking&tag=http

4. POST Requests POST

POST creates a new resource or submits data. The two most common payload types are JSON and form-encoded.

POST with JSON body

import requests

url = "https://httpbin.org/post"
payload = {
    "username": "rwin",
    "role": "admin",
    "active": True,
}

# json= automatically sets Content-Type: application/json and serializes the dict
response = requests.post(url, json=payload)

print(response.status_code)
print(response.json()["json"])   # echoes back what the server received

POST with form-encoded data

import requests

url = "https://httpbin.org/post"
form_data = {
    "email": "user@example.com",
    "password": "hunter2",
}

# data= sends application/x-www-form-urlencoded (classic HTML form behavior)
response = requests.post(url, data=form_data)
print(response.json()["form"])

POST raw bytes / custom body

import requests

raw_body = b'{"raw": true, "note": "manually built JSON"}'

response = requests.post(
    "https://httpbin.org/post",
    data=raw_body,
    headers={"Content-Type": "application/json"},
)
print(response.json()["json"])
data vs json: json=payload sets the header and serializes for you. data=payload (with a dict) form-encodes it. Never pass a dict to data when the API expects JSON — it'll be sent as a form, not JSON.

5. PUT Requests PUT

PUT replaces a resource entirely (idempotent — calling it twice has the same effect as once).

import requests

url = "https://httpbin.org/put"
updated_resource = {
    "id": 42,
    "name": "Full Replacement",
    "status": "active",
}

response = requests.put(url, json=updated_resource)
print(response.status_code)
print(response.json()["json"])

6. PATCH Requests PATCH

PATCH applies a partial update — only the fields you send are changed.

import requests

url = "https://httpbin.org/patch"
partial_update = {"status": "inactive"}

response = requests.patch(url, json=partial_update)
print(response.json()["json"])

7. DELETE Requests DELETE

import requests

url = "https://httpbin.org/delete"
response = requests.delete(url, params={"id": 42})

if response.status_code == 200:
    print("Resource deleted")
else:
    print(f"Delete failed: {response.status_code}")

8. HEAD & OPTIONS

import requests

# HEAD - same as GET but no response body. Great for checking a resource
# exists, its size, or its last-modified date without downloading it.
response = requests.head("https://httpbin.org/get")
print(response.headers.get("Content-Length"))

# OPTIONS - ask the server which methods/headers are allowed (used heavily
# in CORS preflight checks)
response = requests.options("https://httpbin.org/get")
print(response.headers.get("Allow"))

9. Query Parameters — Deep Dive

import requests

# None values are dropped automatically
params = {"active": True, "deleted": None, "limit": 10}
response = requests.get("https://httpbin.org/get", params=params)
print(response.url)  # deleted= is omitted entirely

# You can also just pass a pre-built query string
response = requests.get("https://httpbin.org/get?raw=1&sort=asc")

11. Working with JSON

import requests

response = requests.get("https://api.github.com/repos/psf/requests")

# .json() parses the body into Python dicts/lists
data = response.json()
print(data["stargazers_count"], data["open_issues_count"])

# Handle malformed JSON safely
try:
    data = response.json()
except requests.exceptions.JSONDecodeError:
    print("Response was not valid JSON:", response.text[:200])

# Sending nested JSON structures works exactly like regular dicts/lists
nested_payload = {
    "user": {"name": "Rwin", "roles": ["admin", "dev"]},
    "metadata": {"source": "cli", "version": 2},
}
requests.post("https://httpbin.org/post", json=nested_payload)

12. Form Data

import requests

# application/x-www-form-urlencoded (single values)
requests.post("https://httpbin.org/post", data={"key": "value"})

# Repeated keys: use a list of tuples instead of a dict
form = [
    ("color", "red"),
    ("color", "blue"),
    ("size", "M"),
]
response = requests.post("https://httpbin.org/post", data=form)
print(response.json()["form"])

13. File Uploads (multipart/form-data)

Single file upload

import requests

with open("report.pdf", "rb") as f:
    files = {"file": ("report.pdf", f, "application/pdf")}
    response = requests.post("https://httpbin.org/post", files=files)

print(response.json()["files"].keys())

Multiple files + extra form fields together

import requests

files = {
    "avatar": ("avatar.png", open("avatar.png", "rb"), "image/png"),
    "resume": ("resume.pdf", open("resume.pdf", "rb"), "application/pdf"),
}
data = {"user_id": "1024", "note": "initial upload"}

response = requests.post("https://httpbin.org/post", files=files, data=data)
print(response.status_code)

Downloading a file

import requests

url = "https://httpbin.org/image/png"
response = requests.get(url, stream=True)
response.raise_for_status()

with open("downloaded.png", "wb") as f:
    for chunk in response.iter_content(chunk_size=8192):
        f.write(chunk)

print("Saved downloaded.png")

14. Authentication

Bearer token (most common for APIs)

import requests

headers = {"Authorization": f"Bearer {TOKEN}"}
response = requests.get("https://api.example.com/me", headers=headers)

Basic auth

import requests
from requests.auth import HTTPBasicAuth

# Shorthand tuple form
response = requests.get("https://httpbin.org/basic-auth/user/pass", auth=("user", "pass"))

# Explicit form (identical result)
response = requests.get(
    "https://httpbin.org/basic-auth/user/pass",
    auth=HTTPBasicAuth("user", "pass"),
)
print(response.status_code)  # 200

API key in header or query param

import requests

# In a header (preferred - not logged in URL/proxy logs)
headers = {"X-API-Key": "sk_live_abc123"}
requests.get("https://api.example.com/data", headers=headers)

# In a query param (only when the API requires it)
requests.get("https://api.example.com/data", params={"api_key": "sk_live_abc123"})

Custom auth class (OAuth-style signing)

import requests

class TokenAuth(requests.auth.AuthBase):
    def __init__(self, token):
        self.token = token

    def __call__(self, r):
        r.headers["Authorization"] = f"Token {self.token}"
        return r

response = requests.get("https://api.example.com/me", auth=TokenAuth("abc123"))
Never hardcode secrets. Load tokens from environment variables (os.environ["API_TOKEN"]) or a secrets manager — never commit them to a repo like devforge.

15. Cookies

import requests

# Sending cookies
cookies = {"session_id": "abc123xyz"}
response = requests.get("https://httpbin.org/cookies", cookies=cookies)
print(response.json())

# Reading cookies the server set on you
response = requests.get("https://httpbin.org/cookies/set?theme=dark")
print(response.cookies.get_dict())

# Using a persistent cookie jar across requests
jar = requests.cookies.RequestsCookieJar()
jar.set("session_id", "abc123", domain="httpbin.org")
response = requests.get("https://httpbin.org/cookies", cookies=jar)

16. Timeouts

Always set a timeout. A request with no timeout can hang forever if the server never responds.

import requests

# Single value: applies to both connect and read timeout
response = requests.get("https://httpbin.org/delay/2", timeout=5)

# Tuple: (connect_timeout, read_timeout)
response = requests.get("https://httpbin.org/delay/2", timeout=(3.05, 10))

try:
    response = requests.get("https://httpbin.org/delay/10", timeout=2)
except requests.exceptions.Timeout:
    print("Request timed out after 2 seconds")

17. The Response Object

import requests

response = requests.get("https://api.github.com/repos/psf/requests")

response.status_code     # 200
response.ok               # True if status_code < 400
response.reason           # "OK"
response.url               # final URL after redirects
response.headers          # dict-like, case-insensitive
response.encoding          # detected text encoding, e.g. "utf-8"
response.text               # body decoded as str
response.content           # body as raw bytes
response.json()             # body parsed as JSON
response.elapsed             # timedelta - how long the request took
response.history          # list of Response objects from redirects
response.request           # the PreparedRequest that was sent

print(f"{response.request.method} {response.request.url} -> {response.status_code} in {response.elapsed.total_seconds()}s")

Inspecting redirects

import requests

response = requests.get("http://github.com")  # http -> https redirect
for step in response.history:
    print(step.status_code, step.url)
print("Final:", response.status_code, response.url)

# Disable following redirects entirely
response = requests.get("http://github.com", allow_redirects=False)
print(response.status_code)  # 301

18. Status Codes & Error Handling

RangeMeaningExamples
1xxInformational100 Continue
2xxSuccess200 OK, 201 Created, 204 No Content
3xxRedirection301 Moved, 302 Found, 304 Not Modified
4xxClient error400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 429 Too Many Requests
5xxServer error500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable

raise_for_status()

import requests

response = requests.get("https://httpbin.org/status/404")

try:
    response.raise_for_status()   # raises HTTPError for 4xx/5xx
except requests.exceptions.HTTPError as e:
    print(f"HTTP error: {e}")

Full exception hierarchy

import requests

try:
    response = requests.get("https://api.example.com/data", timeout=5)
    response.raise_for_status()
    data = response.json()

except requests.exceptions.ConnectionError:
    print("Could not connect - check the network or DNS")

except requests.exceptions.Timeout:
    print("Server took too long to respond")

except requests.exceptions.HTTPError as e:
    print(f"Bad status code: {e.response.status_code}")

except requests.exceptions.TooManyRedirects:
    print("Redirect loop detected")

except requests.exceptions.RequestException as e:
    # Base class - catches ANY requests-related exception
    print(f"Request failed: {e}")

Handling rate limits (429)

import time
import requests

def get_with_rate_limit_retry(url, max_retries=5):
    for attempt in range(max_retries):
        response = requests.get(url)
        if response.status_code != 429:
            return response

        retry_after = int(response.headers.get("Retry-After", 2 ** attempt))
        print(f"Rate limited. Waiting {retry_after}s...")
        time.sleep(retry_after)

    raise RuntimeError("Max retries exceeded")

19. Streaming Large Responses

import requests

# Stream instead of loading the whole body into memory at once
with requests.get("https://httpbin.org/stream/20", stream=True) as response:
    for line in response.iter_lines():
        if line:
            print(line.decode("utf-8"))

# Streaming a large file download with progress
def download_with_progress(url, dest_path):
    with requests.get(url, stream=True) as response:
        response.raise_for_status()
        total = int(response.headers.get("Content-Length", 0))
        downloaded = 0

        with open(dest_path, "wb") as f:
            for chunk in response.iter_content(chunk_size=1024 * 64):
                f.write(chunk)
                downloaded += len(chunk)
                if total:
                    pct = downloaded / total * 100
                    print(f"\r{pct:.1f}% downloaded", end="")
    print()

20. Sessions (Connection Reuse)

A Session persists cookies, headers, and connection pools across requests — much faster for multiple calls to the same host, and needed for anything login-based.

import requests

session = requests.Session()
session.headers.update({"Authorization": "Bearer YOUR_TOKEN"})

# Log in - the session automatically stores the returned cookies
session.post("https://httpbin.org/post", data={"user": "rwin", "pass": "secret"})

# Subsequent requests reuse cookies, headers, and the TCP connection
r1 = session.get("https://httpbin.org/get")
r2 = session.get("https://httpbin.org/headers")

session.close()

# Best practice: use as a context manager so it always closes
with requests.Session() as session:
    session.headers.update({"User-Agent": "devforge/1.0"})
    response = session.get("https://api.github.com/user")
Why sessions matter: without one, every requests.get(...) call opens a fresh TCP/TLS connection. A session pools connections via urllib3, cutting latency significantly for scripts making many calls to the same API.

21. Automatic Retries with Backoff

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

session = requests.Session()

retry_strategy = Retry(
    total=5,                              # max retry attempts
    backoff_factor=1,                     # wait 1s, 2s, 4s, 8s, 16s...
    status_forcelist=[429, 500, 502, 503, 504],
    allowed_methods=["GET", "POST", "PUT", "DELETE"],
)

adapter = HTTPAdapter(max_retries=retry_strategy)
session.mount("https://", adapter)
session.mount("http://", adapter)

# Any request that hits a 500/502/503/504/429 is retried automatically
response = session.get("https://httpbin.org/status/503")
print(response.status_code)

Manual retry loop with exponential backoff

import time
import requests

def fetch_with_retries(url, max_attempts=5, base_delay=1):
    for attempt in range(1, max_attempts + 1):
        try:
            response = requests.get(url, timeout=5)
            response.raise_for_status()
            return response
        except requests.exceptions.RequestException as e:
            if attempt == max_attempts:
                raise
            delay = base_delay * (2 ** (attempt - 1))
            print(f"Attempt {attempt} failed ({e}), retrying in {delay}s...")
            time.sleep(delay)

22. Proxies & SSL/TLS

import requests

# Routing traffic through a proxy
proxies = {
    "http": "http://10.10.1.10:3128",
    "https": "http://10.10.1.10:1080",
}
response = requests.get("https://httpbin.org/ip", proxies=proxies)

# Custom CA bundle (e.g. corporate/self-signed certs)
response = requests.get("https://internal.example.com", verify="/path/to/ca-bundle.pem")

# Disable SSL verification (ONLY for local dev/testing - never in production)
response = requests.get("https://self-signed.example.com", verify=False)

# Client certificate authentication (mutual TLS)
response = requests.get(
    "https://secure.example.com",
    cert=("/path/to/client.crt", "/path/to/client.key"),
)
verify=False disables certificate validation — this opens the door to man-in-the-middle attacks. Only use it against a trusted local/test endpoint, and it will spam InsecureRequestWarning unless you silence it deliberately.

23. Async HTTP (httpx & aiohttp)

requests is synchronous only. For concurrent requests (e.g. hitting hundreds of URLs at once), use httpx or aiohttp.

httpx — sync (drop-in requests replacement)

import httpx

response = httpx.get("https://httpbin.org/get")
print(response.status_code, response.json())

httpx — async, single request

import asyncio
import httpx

async def main():
    async with httpx.AsyncClient() as client:
        response = await client.get("https://httpbin.org/get")
        print(response.json())

asyncio.run(main())

httpx — many concurrent requests

import asyncio
import httpx

urls = [f"https://httpbin.org/delay/1?id={i}" for i in range(10)]

async def fetch_all(urls):
    async with httpx.AsyncClient(timeout=10) as client:
        tasks = [client.get(url) for url in urls]
        responses = await asyncio.gather(*tasks, return_exceptions=True)
        return responses

results = asyncio.run(fetch_all(urls))
for r in results:
    if isinstance(r, Exception):
        print("Failed:", r)
    else:
        print(r.status_code)

aiohttp — many concurrent requests with a semaphore

import asyncio
import aiohttp

async def fetch(session, url, semaphore):
    async with semaphore:   # limit concurrency to avoid hammering the server
        async with session.get(url, timeout=aiohttp.ClientTimeout(total=10)) as response:
            return await response.json()

async def main():
    urls = [f"https://httpbin.org/get?id={i}" for i in range(50)]
    semaphore = asyncio.Semaphore(10)   # max 10 requests in flight at once

    async with aiohttp.ClientSession() as session:
        tasks = [fetch(session, url, semaphore) for url in urls]
        results = await asyncio.gather(*tasks)
        print(f"Fetched {len(results)} responses")

asyncio.run(main())
When to reach for async: dozens/hundreds of independent HTTP calls (scraping, health checks, fan-out API calls). For a handful of sequential calls, plain synchronous requests is simpler and just as fast in practice.

24. Pure Standard Library (urllib) — No Dependencies

Useful when you can't install packages (locked-down environments, minimal Docker images, CTF/security constraints).

GET request

from urllib.request import urlopen, Request
from urllib.error import HTTPError, URLError
import json

req = Request(
    "https://httpbin.org/get",
    headers={"User-Agent": "python-urllib/1.0"},
)

try:
    with urlopen(req, timeout=5) as response:
        status = response.status
        body = json.loads(response.read().decode("utf-8"))
        print(status, body)
except HTTPError as e:
    print(f"HTTP error: {e.code} {e.reason}")
except URLError as e:
    print(f"Connection error: {e.reason}")

POST with JSON

from urllib.request import urlopen, Request
import json

payload = json.dumps({"name": "Rwin", "role": "admin"}).encode("utf-8")

req = Request(
    "https://httpbin.org/post",
    data=payload,
    method="POST",
    headers={"Content-Type": "application/json"},
)

with urlopen(req, timeout=5) as response:
    result = json.loads(response.read())
    print(result["json"])

Query string encoding

from urllib.request import urlopen
from urllib.parse import urlencode

params = {"q": "http requests", "page": 2}
url = f"https://httpbin.org/get?{urlencode(params)}"

with urlopen(url, timeout=5) as response:
    print(response.read().decode())

25. Real-World Patterns

Pattern: Simple API client class

import requests

class GitHubClient:
    def __init__(self, token=None):
        self.base_url = "https://api.github.com"
        self.session = requests.Session()
        self.session.headers.update({"Accept": "application/vnd.github+json"})
        if token:
            self.session.headers["Authorization"] = f"Bearer {token}"

    def get_user(self, username):
        response = self.session.get(f"{self.base_url}/users/{username}", timeout=5)
        response.raise_for_status()
        return response.json()

    def list_repos(self, username, per_page=30):
        response = self.session.get(
            f"{self.base_url}/users/{username}/repos",
            params={"per_page": per_page, "sort": "updated"},
            timeout=5,
        )
        response.raise_for_status()
        return response.json()

    def close(self):
        self.session.close()


client = GitHubClient()
user = client.get_user("octocat")
print(user["name"], user["public_repos"])
client.close()

Pattern: Paginated API fetching

import requests

def get_all_pages(url, params=None, session=None):
    """Follows GitHub-style Link headers until there is no 'next' page."""
    session = session or requests.Session()
    results = []

    while url:
        response = session.get(url, params=params, timeout=5)
        response.raise_for_status()
        results.extend(response.json())

        # parse the Link header: ; rel="next"
        next_url = None
        for link in response.links.values():
            if link.get("rel") == "next":
                next_url = link["url"]

        url = next_url
        params = None   # params are already baked into next_url

    return results

all_repos = get_all_pages(
    "https://api.github.com/orgs/python/repos",
    params={"per_page": 100},
)
print(len(all_repos), "repos fetched")

Pattern: Simple webhook / API health checker

import requests
from datetime import datetime

def check_endpoint(url, expected_status=200, timeout=5):
    try:
        response = requests.get(url, timeout=timeout)
        healthy = response.status_code == expected_status
        return {
            "url": url,
            "healthy": healthy,
            "status_code": response.status_code,
            "latency_ms": round(response.elapsed.total_seconds() * 1000, 1),
            "checked_at": datetime.utcnow().isoformat(),
        }
    except requests.exceptions.RequestException as e:
        return {
            "url": url,
            "healthy": False,
            "error": str(e),
            "checked_at": datetime.utcnow().isoformat(),
        }

endpoints = [
    "https://httpbin.org/status/200",
    "https://httpbin.org/status/500",
]
for ep in endpoints:
    print(check_endpoint(ep))

Pattern: Retrying + JSON schema validation for an unreliable API

import time
import requests

REQUIRED_KEYS = {"id", "name", "status"}

def fetch_valid_json(url, max_attempts=3):
    for attempt in range(1, max_attempts + 1):
        try:
            response = requests.get(url, timeout=5)
            response.raise_for_status()
            data = response.json()

            if not REQUIRED_KEYS.issubset(data.keys()):
                raise ValueError(f"Missing keys: {REQUIRED_KEYS - data.keys()}")

            return data

        except (requests.exceptions.RequestException, ValueError) as e:
            print(f"Attempt {attempt} failed: {e}")
            if attempt < max_attempts:
                time.sleep(1.5 * attempt)

    raise RuntimeError(f"Failed to fetch valid data from {url} after {max_attempts} attempts")

26. Security Notes

Always validate SSL certs. Never ship code with verify=False against a production/internet-facing host.
Set timeouts on everything. An HTTP client with no timeout is a resource-exhaustion bug waiting to happen.
Never log full Authorization headers or tokens. Mask them (Bearer ****abcd) if you must log requests for debugging.
Sanitize user-supplied URLs before making server-side requests to them — unrestricted requests to user input is how SSRF vulnerabilities happen.
Respect rate limits and robots.txt when scraping. Add a real User-Agent and back off on 429s instead of hammering a server.
Store secrets in environment variables (os.environ) or a secrets manager — never hardcode API keys/tokens in source.
